# Mở thử NhTBank 1.1

Tải `NhTBank-Android.html` hoặc `NhTBank-Windows.html`, rồi mở tệp bằng Chrome/Chromium/Edge hiện đại. PIN dùng thử: **123456**.

Các tệp chứa đầy đủ bản build React, CSS và font; không cần CDN hoặc cài npm để xem thử. Có thể đổi bố cục bằng liên kết Điện thoại / Máy tính. Chỉ mô phỏng; dữ liệu mất khi tải lại hoặc đăng xuất. Không có giao dịch tiền thật.

Để tái tạo từ mã nguồn: `npm ci`, `npm run build`, `node scripts/export-standalone.mjs exports`.
