# NhTBank MagicPath UI prototype

Mẫu giao diện xanh cyan → blue → tím, bề mặt bóng 3D, chuyển động nhẹ và thanh điều hướng 5 mục.

- `NhTBankGiaoDiNNgNHNgS.tsx`: React + TypeScript component.
- `NhTBankGiaoDiNNgNHNgS.css`: CSS self-contained.

Đây là **prototype riêng**, không nhập vào luồng banking hiện tại cho tới khi kiểm thử bảo toàn nghiệp vụ. Phần minh họa QR không tạo mã QR thanh toán. PIN công khai chỉ là trải nghiệm demo.
